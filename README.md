# 💻 L.Bhivgade™ — Interactive Terminal Portfolio

Welcome to the source code of my personal portfolio website! This project is designed to be **bold, fearless, and premium**, combining a retro CRT/Terminal aesthetic with modern, smooth web animations.

## ✨ Features

- **Terminal-Style UI:** Custom CSS-driven interface that mimics vintage command lines while maintaining a premium, modern feel.
- **Dynamic Light/Dark Contrast:** Alternating theme sections (Dark Home → Light Dossier → Light Skills → Dark Creations → Light Contact) designed to keep users engaged and highlight critical information.
- **Draggable Matrix Skills:** An interactive physics-inspired skills wall built with custom JS and CSS variables.
- **GSAP Animations:** High-performance scroll-triggered animations and text reveal effects.
- **Serverless Contact Form:** Fully integrated with Google Apps Script to securely post messages directly into a private Google Sheet.
- **Fully Responsive:** Optimized mobile layouts using CSS Grid and Flexbox for seamless viewing on any device.

## 🛠️ Technology Stack

- **Structure:** Semantic HTML5
- **Styling:** Vanilla CSS (CSS Variables, Grid, Flexbox, custom typography)
- **Logic:** Vanilla JavaScript (ES6+)
- **Animation:** GSAP (GreenSock Animation Platform) + ScrollTrigger
- **Backend (Contact Form):** Google Apps Script (Web App API)

## 🚀 Running Locally

Because this project is built entirely with frontend web technologies, you don't need any complex build tools to run it.

1. Clone the repository:
   ```bash
   git clone https://github.com/LakshyaBhivgade4/portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```
3. Open `index.html` in any modern web browser, or use a tool like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code for hot reloading.

## 📂 Structure

- `index.html` - The main structure of the single-page application.
- `style.css` - All styling, responsive rules, and keyframe animations.
- `script.js` - GSAP triggers, interactive logic (draggable elements, typing effects), and form submission API requests.
